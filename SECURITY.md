# Security Policy

## Supported Versions

OpenTally is under active development. Security updates are applied to the active branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of OpenTally and financial accounting data very seriously.

If you discover a security vulnerability, data loss risk, or cryptographic flaw, please **do NOT report it via a public GitHub issue**.

Instead, please report security vulnerabilities responsibly by:
1. Opening a **GitHub Private Vulnerability Report** via the repository's Security tab at `https://github.com/Sanvith6/OpenTally/security/advisories/new`, OR
2. Contacting the maintainers directly via email at `sanvitjs68@gmail.com`.

### What to Include in Your Report
- A description of the vulnerability and its potential impact.
- Step-by-step reproduction steps or a minimal proof of concept.
- Affected components (e.g. SQLite database layer, IPC bridge, frontend input validation).
- Any proposed remediation or mitigation.

### Disclosure Policy
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will work diligently to confirm the issue and develop a fix in a timely manner.
- We kindly ask that you keep the issue confidential until a security patch has been released.
