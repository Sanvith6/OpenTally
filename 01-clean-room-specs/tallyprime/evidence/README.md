# TallyPrime Observable Evidence

Store observable network captures, XML sample envelopes, sanitized log snippets, and test fixtures here.

All artifacts in this folder must represent external observable behaviors (e.g. HTTP traffic on port 9000). Every evidence recording must be accompanied by a YAML manifest complying with [`EVIDENCE_SCHEMA.md`](file:///c:/project/OpenTally/01-clean-room-specs/tallyprime/evidence/EVIDENCE_SCHEMA.md) (see [`EVIDENCE_TEMPLATE.yaml`](file:///c:/project/OpenTally/01-clean-room-specs/tallyprime/evidence/EVIDENCE_TEMPLATE.yaml)).

> [!WARNING]
> Under no circumstances may proprietary binaries, proprietary database files (`.tsf` or company folders), raw TDL source code, or extracted proprietary assets be stored here.
