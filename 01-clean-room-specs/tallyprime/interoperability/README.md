# Interoperability Specifications

Specifications covering:
- Tally XML Interface over HTTP (Port 9000):
  - Request/Response `<ENVELOPE>` structure.
  - Export requests (`<TALLYREQUEST>Export Data</TALLYREQUEST>`).
  - Import requests (`<TALLYREQUEST>Import Data</TALLYREQUEST>`).
  - TDL Collection query formats and `<STATICVARIABLES>`.
- ODBC query interfaces and table schemas.
- Data exchange formats (JSON, XML, CSV).
